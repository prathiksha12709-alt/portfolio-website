## 🌐 Publishing to GitHub Pages

1. Go to your repository on GitHub: `https://github.com/prathiksha12709-alt/prathiksha-portfolio`
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) branch and folder `/ (root)`.
4. Click **Save**.
5. Your portfolio website will be live at:  
   **`https://prathiksha12709-alt.github.io/prathiksha-portfolio/`**
